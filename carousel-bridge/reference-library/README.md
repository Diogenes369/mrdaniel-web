# Few-shot visual layout anchors

Drop reference sketchnote screenshots here as `.png` / `.jpg`. Every file in this folder is passed
to Hermes during art direction as a permanent style anchor, so the generated layouts converge on
your house style instead of drifting each run.

Guidance:
- 2-5 images is the useful range; more dilutes rather than sharpens.
- Pick examples that differ in STRUCTURE (a 2-card comparison, a 3-step sequence, a single hero
  stat), not just in colour — structure is what the model reuses.
- Anything here is treated as style-only. Subject matter is never copied.

**This folder is currently empty** — no reference screenshots have been supplied yet. Until it has
files, art direction runs on the written design system alone.
